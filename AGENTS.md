# AGENTS.md

Instructions for AI coding agents working in this repository.

## Project overview

🧠 Полимат = Мультиагент — параллельная оркестрация ИИ-агентов: несколько независимых исполнителей на одном мандате Хозяина.

## Commands

Автоматика ведётся воркфлоу `.github/workflows/`; перед изменением смотри
существующие файлы и следуй их паттернам. Чужих агентов не глушить.

## Conventions

- Минимальные, сфокусированные изменения; одна логическая мысль — один коммит
  (формат `тип(область): суть по-русски`).
- Никогда не коммитить секреты, токены, ключи: секреты живут в локальных файлах вне git-слежки.
- README.md обновлять при изменении поведения или структуры.
- Перед коммитом прогонять доступные проверки; зелёный CI — закон дома
  (устав: `rtynbirf/repo-doctrine`).
- Правило аддитивности: добавлять можно; удалять чужое и переписывать историю — нельзя
  (откат — только `git revert`, никогда force-push).

## Канон косЯков (обязателен для всех агентов, не совет)

1. ПЕРВЫМ ДЕЛОМ, до любой правки кода: прочитай [MISTAKES.md](MISTAKES.md)
   целиком. Незнание косЯков не освобождает от их повторения.
2. В работе: любая ошибка (упавший тест, неверное предположение, кривая
   правка, гонка, подгонка) фиксируется сразу, пока свежа причина.
3. Перед финальным коммитом волны: свои косЯки дописываются в
   `MISTAKES.md` по формату журнала (Симптом / Причина / Исправление /
   Урок). Ошибка закрыта, только когда у неё есть урок-правило.
4. «Поправил, но не записал» = косЯк. Молчание невозможно: формат журнала
   и порядок чтения проверяются кодом (`tests/test_canon.py`).
5. Журнал только растёт: чужие записи не вычёркиваются, не переписываются
   и не «улучшаются» — правило аддитивности действует и на него.
6. Порядок работы агента: **MISTAKES.md → AGENTS.md → README → код**.
