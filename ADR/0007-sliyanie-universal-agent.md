# ADR-0007: Слияние близнецов — universal-agent поглощён polymath-multiagent

Статус: ПРИНЯТ (хозяин приказал: один каркас, дубли не плодить) · Дата: 2026-11-20 · Контекст: ратчет 0.5.1 → 0.6.0

## Контекст
В доме жили два агентных каркаса: polymath-multiagent (оркестратор роя,
24 py-файла, 4599 строк, 99 test-функций) и universal-agent/ЦУА (одиночный
мозг: память SQLite, инструменты, песочница, 15 py-файлов, 2387 строк,
52 test-функции). Статический разбор (research/twins_compare.json):
пересечение имён def/class — 19 из 359 (5%); байт-идентичных файлов — 1
(.github/workflows/witness-swarm.yml); revo_autopilot.py присутствует в
обоих как разошедшийся форк (дубль, подлежащий канонизации в одном месте).

## Решение
Выживший — polymath-multiagent (живее: больше кода/тестов/CI, дом-боты,
MCP-server). ЦУА переносится как пакет universal/ (brain.py — без правок
кода, только окружение), мост polymath/universal_bridge.py делает мозг
обычным агентом роя с уникальным навыком universal-solve. Дубль навыка
запрещён контрактом оркестратора (DuplicateSkillError) — слияние
гарантированно не создаёт второго ЦУА.

## Последствия
+ один каркас вместо двух, наследование истории обоих;
+ ЦУА получает параллельность роя, рой — память и руки ЦУА;
− universal-agent подлежит удалению на GitHub ПОСЛЕ push 0.6.0
  (команда в отчёте о слиянии); до того — никакой перезаписи;
− hologram.json пересобирается ботом после удаления дубля.

## Проверка
pytest: 99 (A) + 52 (ЦУА, адаптированы) + 3 (мост) — все зелёные локально.
