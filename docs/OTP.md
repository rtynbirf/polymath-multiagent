# ПИД1 против OTP-супервайзера: построчное сравнение, доказанное машиной

> «Одно другое не исключает.» — учиться у гуру и отходить от них сознательно —
> тоже «одно» и «другое».

В `polymath/automaton.py` оба надзора — конечные автоматы: ПИД1 (`TABLE`, 7
состояний × 7 символов) и OTP `one_for_one` (`OTP_TABLE`, в тех же символах).
Построчное сравнение — не эссе, а исполняемая теорема:

- **Теорема о ядре** (`tests/test_automaton.py::test_otp_core_theorem_holds`):
  на алфавите `{pid1_started, pid1_round, pid1_child_up, pid1_child_down}`
  обе машины **эквивалентны** при допуске «надзор жив» (ПИД1: `работа`,
  `лечение`; OTP: `работа`, `рестарт`). Проверка — обход произведения
  автоматов (Хопкрофт–Уллман): ни одна пара состояний в произведении не
  различима допуском.
- **Антитеорема** (`test_departures_from_otp_are_proven_by_machine`): на
  полном алфавите эквивалентности **нет** — ровно на трёх символах,
  все три отступления сознательны.

## Построчная таблица

| Символ | ПИД1 (наша δ) | OTP one_for_one (в наших символах) | Вердикт машины |
|---|---|---|---|
| `pid1_started` | `ожидание → работа` | `покой → работа` | **совпадает** (ядро) |
| `pid1_round` | `работа → работа`, `лечение → работа` | `работа → работа`, `рестарт → работа` | **совпадает** (ядро) |
| `pid1_child_up` | `работа/лечение → работа` | `работа/рестарт → работа` | **совпадает** (ядро) |
| `pid1_child_down` | `работа → лечение` | `работа → рестарт` | **совпадает** (ядро): рестарт = новый раунд того же ребёнка |
| `pid1_quarantined` | `работа/лечение → карантин` — исчерпавший бюджет ребёнок заморожен, **экипаж продолжается** | `→ тупик` — при breach интенсивности OTP-супервайзер **умирает целиком** и тянет весь ствол надзора вверх | **отступление №1** |
| `pid1_verdict` | `работа → доверие ✓` — вердикт с гёделевыми пределами (`LIMITS`) | `→ тупик` — OTP не отчитывается о своей полноте | **отступление №2** |
| `pid1_degraded` | `работа/лечение/карантин → опыт ✓` — раунды исчерпаны честно, частичный урожай отдан | `→ тупик` — у OTP нет понятия «деградировавший, но честный результат» | **отступление №3** |

## Три отступления и почему они сознательные

1. **Карантин вместо смерти надзора.** В OTP исчерпание `max_restarts`/
   `max_intensity` за `period` убивает самого супервайзера (и каскадом — всю
   ветку дерева). У ПИД1 ребёнок изолируется, экипаж докручивает мандат без
   него, ПИД1 жив. Причина: экипаж Полимата — разовые навыки без дублей
   (контракт `DuplicateSkillError`), потеря любого ребёнка невосполнима в
   пределах прогона, поэтому «валить всех» — худшая из стратегий.
2. **Вердикт с пределами.** OTP ничего не доказывает о себе. ПИД1 после
   чистого раунда проходит аудит трёх инвариантов и декларирует собственную
   неполноту (Гёдель II: `polymath.LIMITS`). Причина: надзор без заявления
   пределов превращается в самоуверенность.
3. **Деградация как допуск.** Если чистого раунда не случилось, ПИД1 отдаёт
   собранное («опыт», допускающее состояние), помечая прогон честным
   частичным результатом. OTP не имеет такого исхода: либо рестарт, либо
   смерть. Причина: падение — данные, а не приговор (эмпатия).

## Что у гуру взято честно

- `one_for_one`: падение ребёнка не трогает остальных — **ядро доказано
  эквивалентным машиной**, а не «по мотивам»;
- рестарт с паузой и потолком — systemd (`RestartSec`, экспоненциальный
  backoff, `RestartMaxDelaySec`);
- ПИД1 не умирает, зомби переполучаются — Unix init(8): инвариант
  `attempts == completions + restarts` ловится тестом;
- LFS-дух: обе таблицы живут в stdlib-only Python — ноль рантайм-зависимостей.

## Воспроизвести

```bash
pytest tests/test_automaton.py -q          # экзамены теории
polymath automat                            # живой прогон: слово → «доверие»
python -c "from polymath.automaton import TABLE, OTP_TABLE, equivalent, \
    INITIAL, OTP_INITIAL, ALPHABET, CORE_ALPHABET, PID1_ALIVE, OTP_ALIVE; \
    print(equivalent(TABLE, INITIAL, PID1_ALIVE, OTP_TABLE, OTP_INITIAL, OTP_ALIVE, CORE_ALPHABET))"
# True — теорема о ядре
```
